## 首頁區塊順序

1. **Hero** — 主視覺 3D／shader + 活動名稱、日期、地點、報名 CTA。
   關鍵資訊必須是**真實 DOM 文字**，不可燒在 canvas 或圖片裡（SEO 與無障礙）。
2. **這是什麼** — 一段話說明 QRACON 定位與今年主題。
3. **亮點數字** — 屆數、講者數、參與人數（承自 2025 數據）。
4. **議程預告／講者卡** — 議程未定前先放「議程籌備中」與 CFP 入口。
5. **地點與交通** — 中研院南部院區，含地圖與交通方式摘要，連往 `/venue`。
6. **贊助商牆** — 招商後填入。
7. **Footer** — 主辦資訊、社群連結、聯絡信箱、CoC 連結。

## 議程表設計（`/agenda`）

參考 SITCON 的互動模式，但簡化——QRACON 是單日、廳數少。

- **桌機**：縱軸時間、橫軸議程廳的網格。
- **行動**：同一份資料退化為時序清單（**不是隱藏，是重排**）。
- **議程詳情**走獨立靜態路由 `/agenda/[id]`，不用 modal——可分享、可被搜尋、可直連。
- **個人收藏**：星號加入我的議程，存 `localStorage`，不需登入與後端。
- **篩選**：依議程類型與主題標籤。QRACON 的類型待定（Keynote／短講／工作坊／海報／論壇？）。
- 資料來源 `src/data/sessions.ts`，型別化。

### 資料型別草案

```ts
type Session = {
  id: string;
  title: string;
  speakerIds: string[];
  room: string;
  start: string; // ISO 8601
  end: string;
  type: SessionType;
  tags: string[];
  abstract: string; // markdown
  slidesUrl?: string;
  videoUrl?: string;
};
```

## 會場地圖（`/venue`）

**分兩層做，順序不可顛倒：**

1. **資訊層（必做，P1）** — 2D SVG 分層平面圖 + 樓層／區域切換 + 空間清單。
   這是當天真正被用來找路的東西：手機開得快、離線可讀、可放大、可搜尋。
2. **體驗層（加分，P4 後段）** — Three.js 3D 模型。時程不足時**直接砍掉**，不影響可用性。

另需：中研院南部院區的交通方式（自行開車／高鐵／台鐵／接駁），
以及院區內從大門到會場的步行指引——外地與會者最需要的其實是這段。

## 內容承接自 QRACON 2025

可沿用、需更新年度資訊的內容：

- QRACON 名稱內涵與六大核心訴求（優質講座、遊戲化、量子競賽推廣、教育合作、
  海報與遊戲、銜接中學至大學）。
- 活動定位：促進學界、產業界、教育端的交流與融合。
- 主辦背景與歷屆回顧。

**不沿用**：2025 的「Planck 100」主題論述（時效已過）、任何 2025 的版面與視覺。
